DZ LIFE — Algerian Life Simulator
MVP playable mobile web game.

How to play:
1. Open index.html in a modern browser on Android or desktop.
2. Create a character.
3. Each "LIVE ONE YEAR" advances the simulation.
4. Use the tabs for careers, businesses, shopping, real estate, crypto, economy and timeline.
5. Save uses the browser's localStorage.

This is a lightweight prototype. The economy, prices, events and fictional crypto are game systems, not real-world financial data.
